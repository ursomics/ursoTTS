# 2. 알파벳 약어
DNA와 RNA를 추출하고, ATP를 측정한 뒤, qPCR로 결과를 확인했습니다. AUC는 높았고 FDR은 낮았습니다. 샘플은 FACS로 분리했고, mRNA 수준은 단백질 데이터와 일치했습니다.

# 3. 시퀀싱 방법과 분석 도구
RNA-seq, scRNA-seq, 그리고 ATAC-seq을 수행했고, Visium HD로 조직을 매핑했습니다. PCA 후에 UMAP으로 클러스터를 보여 주었습니다. 발현 차이는 R에서는 DESeq2로, Python에서는 PyDESeq2로 분석했고, 싱글셀 데이터는 Scanpy로 분석했습니다.

# 4. 단어처럼 읽는 유전자
Myc과 RAS는 세포 증식을 이끌고, Wnt 신호는 조직을 형성하며, Fos는 몇 분 안에 반응합니다. NANOG와 SOX17은 초기 세포 운명을 표시하고, LAGE는 일부 종양에서 발현됩니다.

# 5. 문자와 숫자가 섞인 유전자
GATA3, GATA4, GATA6은 서로 다른 계통을 조절합니다. TP53과 BRCA1은 대표적인 종양 억제 유전자이고, EGFR과 APC는 자주 돌연변이가 생깁니다. IL2RA는 조절 T 세포에서 높게 발현됩니다.

# 6. 대소문자가 섞인 유전자
Foxp3는 조절 T 세포의 핵심 조절인자입니다. 마우스에서는 Cd8a와 Cd4가 두 주요 T 세포 집단을 표시합니다.

# 7. 면역학 용어와 복수형
CD8 T 세포와 CD4 T 세포를 비교했습니다. 같은 세포에서 TCRs와 BCRs를 시퀀싱했습니다. NK 세포는 KIR 수용체를 발현했고, HLA와 MHC class I 분자를 인식했습니다.

# 8. 하이픈과 그리스 문자
PD-1, PD-L1, 그리고 CTLA-4를 차단하자 반응이 강해졌습니다. 세포들은 IFN-gamma, TNF-alpha, 그리고 IL-2를 분비했습니다.
